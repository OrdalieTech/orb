# Upstream sync report — 2026-10-02

Status: **GREEN**. Pinned to released Pi **v1.0.0** (`a13d35a742c6ef8462812a28fbe1d8c8b7431c32`),
from v0.86.0, under P5 as amended the same day: interop with released Pi, improvements allowed,

## Delta

1177 upstream paths changed across seven releases (0.86.1, 0.87.0, 0.87.1, 0.99.0, 0.99.1,
0.99.2, 1.0.0): 152 kernel paths (75 wire, 77 API) and 1025 optional. Codemode, classifier
models, virtual models, Radius and Pi's `system` theme stay out (divergence ledger).

## Extraction

The extractors now run at v1.0.0. Upstream deleted its experimental harness, so `F6Harness*` and
the harness parts of F8 and F10 are Orb-owned and carried from the committed tree
(`conformance/extract/orb-owned.ts`); the split-turn compaction case moved back to upstream
extraction through the product compactor. Fixture tools follow 1.0's pins (openai 7.19.0,
vitest 4.1.11) plus TypeScript 5.9.3 for the command-metadata parser, which TypeScript 7 no longer
ships. Canonical fixtures are extracted on Linux (`.tools/extract-linux.sh` in the
`golang:1.27.1` + Node 24 image) from a copy of the repository whose `.upstream` is the pin,
since the extractors import `../../.upstream` statically.

- Agent loop: `finishTurn` (replaces `shouldStopAfterTurn`), `prepareRequest`, explicit
  continuation, `thinkingLevel` on assistant messages.
- Sessions: `context_edit` entries and projection; each request is the session's projection;
  retry and overflow recovery persist omissions as `entry_appended` events; files are created at
  the first user or assistant message; `refreshContext` after new-session setup.
- RPC input dispositions; tool `isError` and `structuredContent`; bash's structured result.
- Providers: strict schemas opt-in for OpenAI-compatible endpoints, Sign in with ChatGPT and its
  field omissions, Meta (API key and Muse login), the Codex rename, Claude Code 2.1.280,
  pi-messages and Codex WebSocket partials as of emission.
- Catalog: model `type` and image input limits, Claude Opus and Sonnet 5.5, the GPT-6 family,
  Meta Muse Spark, OpenAI list prices, xAI context tiers, Mistral effort levels, compat flags in
  upstream's spread order. Diffed model by model against 1.0's generator on the same snapshots:
  the remaining differences are NVIDIA and Qwen token-plan listing stubs, not 1.0 changes.
- Themes: `#rgb`, `oklch()`, `okhsl()`, `appearance`; export palettes and token order; templates.
- Prompt templates report malformed frontmatter; the turn-prefix summary prompt.
