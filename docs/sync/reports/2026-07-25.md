(`20be4b18d4c57487f8993d2762bace129f0cf7c6`). This is a survey pass: the extraction
tooling was repaired so the candidate revision can be measured, and the measurement is
recorded below. No 0.82.x behavior was ported.

refinement — fixtures extracted at *both* revisions from the same clone on the same machine, and
`go test -race ./...` run against each — because the single-sided comparison the tool performs
against the committed goldens is polluted by the environment sensitivities documented at the end
of this report. Re-running `make sync` will overwrite this file with the tool's own narrower view.

## Extraction is not reproducible on macOS

Regenerating the fixtures at the **pinned** commit on this machine already differs from the
committed goldens in nine files, and the pinned baseline suite fails 41 test names. None of it
is upstream drift; the goldens are pinned to the Linux CI environment:

- **Terminal colour depth.** The interactive theme resolves `chalk`'s level at first import, before
  the F12 extractors set `FORCE_COLOR`. A developer shell exporting `COLORTERM=truecolor`
  produces `\e[38;2;R;G;B` where the goldens hold `\e[38;5;N`, rewriting
  `F12-app/status-frames.json`, `F12-commands/commands.json`, `F12-ui-lifecycle/lifecycle.json`,
  `F12-visible-commands/cases.json` and `WP450-session-selector/selector.json`. `generate.ts`
  already deletes `COLORTERM`, but that runs after the sibling extractor modules are evaluated.
- **Case-insensitive filesystem.** APFS resolves `AGENTS.MD` to `AGENTS.md`, moving `F9/cases.json`.
- **Ambient Google ADC.** `F2/google-vertex-provider.json` records `"adc": "<authenticated>"` only
  when the extracting machine has application-default credentials.
- **macOS `TMPDIR` symlinks** move `F6Harness/observations.json` and the `symlinkCanonical` /
  `preAborted` harness cases.
- **A nondeterministic fixture.** `F12-commands/commands.json` records the `/debug` output path,
  which contains a random `mkdtemp` suffix, plus that file's SHA-256 — so it differs on every
  extraction regardless of platform.

Consequence: `make fixtures-check` and `make sync` are only trustworthy on Linux, or via the
A/B method used here. This should be fixed before the next sync attempts a bump.

## What landed in this pass

Extraction repairs only — no product behavior changed.

- `conformance/extract/upstream-model-data.ts` — synthesizes `providers/data/.manifest.json`
  (upstream ≥0.82.0 statically imports it from `providers/all.ts`) and adds
  `writeProviderModelData`, which writes synthesized catalogs flat or grouped-by-API depending on
  whether the checked-out `<provider>.models.ts` uses `flattenModelCatalog`.
- `conformance/extract/f2-{anthropic,bedrock,google,google-vertex}.ts` — use it, so the
  `apis` list of every provider fixture stops collapsing to `[]` / `[null]` at ≥0.82.0.
- `conformance/extract/f2-anthropic.ts` — the provider probe records `resolved.auth` verbatim
  instead of asserting an `apiKey`, so a headers-only resolution is captured rather than crashing
  extraction.
- `conformance/extract/f2-providers.ts` — `providerApis` exported; `f2-codex.ts` derives
  subscription-provider APIs from the provider factory instead of a `Model<"api">` regex over the
  generated catalog, which 0.82.0 no longer emits.
- `conformance/extract/f12-visible-commands.ts` — the `/models` harness supplies the session
  scope and settings that `showModelsSelector` now reads before its early return.

All five are byte-neutral at the pinned commit for every fixture they touch.
